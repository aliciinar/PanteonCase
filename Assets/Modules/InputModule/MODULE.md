# Input

## Purpose
Reads the pointer through the Input System and announces presses, drags and releases that start on the game world - in world units - so other modules never touch raw input. Presses that start over UI are left to the UI; only that one happened is announced (`Outgoing.PointerPressedOverUI`, no position, no drag or release) - the units module drops its selection on it. Presses and releases are always heard (selecting a building needs them); a press's moves are read only between `Incoming.StartListeningToDrag` and `Incoming.StopListeningToDrag` - while a building is being placed - so outside a placement the pointer's movement is never read, converted or announced. The secondary button (`Board/SecondaryPress`, the right mouse button - units' move orders) is announced as `Outgoing.PointerSecondaryPressed` where it goes down on the world; it has no drag or release. The pointer is polled from the frame either button goes down until both are up (`PressesEnded`).
