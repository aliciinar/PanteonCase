# GameBoard

## Purpose
Draws the game board: reads the grid size, cell size, frame padding and cell sprite from CD_GameBoard, has the grid service lay the grid out centred on the world origin, draws the frame 9-sliced and the cells as one Tilemap, and announces the board's bounds. Knows no building or unit.

## Concepts
game board, board frame, grid drawing, tilemap, cell sprite, board bounds, CD_GameBoard, GameBoardCVO, IGameBoardModel, BuildGameBoardCommand

## Decisions
- The cells are a Tilemap, not an object per cell: one mesh, built once when the board is drawn. The Grid's cell size is the cell sprite's own size and the Grid is scaled to the board's cell size, so any grid size and cell size draw right. The grid service's cells stay the truth - the Tilemap only draws them. A cell can later be coloured with `Tilemap.SetColor` once the tile's `LockColor` flag is cleared.
