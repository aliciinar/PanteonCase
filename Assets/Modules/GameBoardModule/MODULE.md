# GameBoard

## Purpose
Owns the game board: reads the grid size and cell size from CD_GameBoard, decides where every cell sits in the world, draws the framed grid and announces the board's bounds. Finds free areas on the grid; a building picked in the production menu is previewed there as a ghost with a confirm / cancel prompt, and placed (cells occupied, building shown as large as its footprint in CD_BoardBuildings) when the player confirms.
