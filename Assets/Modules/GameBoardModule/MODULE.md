# GameBoard

## Purpose
Owns the game board: reads the grid size and cell size from CD_GameBoard, decides where every cell sits in the world, draws the framed grid and announces the board's bounds. Finds free areas on the grid and shows the buildings picked in the production menu on it, each as large as its footprint in CD_BoardBuildings.
